## COMP2068 JavaScript Frameworks - First Node App

# Terminal Commands

Verify Node installation: `node -v`

Install TypeScript for Node: `npm i typescript @types/node`

Transpile TypeScript to JavaScript: `npm run build`

Run any JavaScript file from the <strong>dist</strong> (output) directory: `node dist/{fileName}.js`

Clear Terminal: `cls`

Repeat Last Command(s): &#8593;
